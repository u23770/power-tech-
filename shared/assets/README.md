# Brand assets

Place the store logo here as **`power-tech-logo.png`** (exact filename, path `shared/assets/power-tech-logo.png`).

- The logo is supplied by the owner. It must not be redrawn, recolored, or recreated in code.
- Until the file exists, the header shows the text wordmark only (the broken image is hidden automatically).
- Used by: customer pages, admin header, `<link rel="icon">`, and Open Graph metadata.
- Recommended: a square PNG of at least 512×512 px with a transparent or dark-compatible background.
